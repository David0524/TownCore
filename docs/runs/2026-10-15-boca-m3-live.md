`pnpm ingest:once boca-raton`, then `pnpm stories:once boca-raton` (new; same code path as the

## Model provider: not available

`GEMINI_API_KEY` was not in this session's environment, and Google returned 401
CREDENTIALS_MISSING for `generativelanguage.googleapis.com` without it. So this pass ran the
code-only parts of M3. The classify, writer and fact-check calls did not run; the 5 candidates
that need them are `pending`. Nothing was mocked.

To finish the pass: add `GEMINI_API_KEY` (or `ANTHROPIC_API_KEY`) as an environment variable in
the cloud environment settings, start a new session, and run the four commands above again.

## Bug found and fixed

The first contractor-license roundup listed "Construction Business Information, license QB"
lines and said 5 licenses instead of 3. DBPR's QB rows register the company a licensed qualifier
works under; they have no license number. The finder now counts only rows with a license number
(`isIssuedLicense` in `packages/pipeline/src/templates.ts`), with tests.
